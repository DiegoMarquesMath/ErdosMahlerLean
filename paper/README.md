# Frozen mathematical source

`bootstrap.sh` copies the user's own two source files here from the Desktop folder `Lean4 EM`:

- `Erdos_MahlerREV.tex`
- `Erdos_MahlerREV.pdf`

The file `SHA256SUMS` is generated locally on the user's Mac. Whenever source content changes, create a new provenance checkpoint and verify that changes do not silently invalidate the Lean theorem statements. Do not modify a frozen source in place without updating hashes and status.
